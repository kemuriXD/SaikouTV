# Saikou TV — Archived

> [!IMPORTANT]
> Saikou TV is no longer actively maintained. This repository is preserved as a historical reference, and no further updates or fixes are planned.

## Project status

The existing source code and [legacy releases](https://github.com/kemuriXD/SaikouTV/releases) remain available.

Existing installations may continue to work, but compatibility with streaming sources, catalogue services and account integrations is no longer maintained. Previous source-status information should be considered outdated.

This archived repository is no longer accepting new development, bug fixes or feature requests.

## Thank you

Thank you to the original Saikou developers, everyone who contributed to Saikou TV, and the community members who tested builds, reported problems and supported the project.
